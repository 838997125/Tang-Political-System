# 🔬 科研流程总纲 · Research Workflow

> **像公司一样做科研**：阶段关卡（Stage-Gate）管理 + 明确角色分工（RACI）+ 强制同行评审 + 全程可审计。
>
> 本文档是 Tang Political System 科研模式的最高纲领。所有 Agent 的科研行为以本文档及 [科研 SOP 检查清单](research-sop.md) 为准。

---

## 一、设计理念：把科研当成一家公司的主营业务

一家运转良好的研究型公司，做科研不是靠灵感，而是靠**流程**：

| 公司管理实践 | 本系统的科研对应 |
|---|---|
| 立项委员会审批项目 | 门下省 G1 立项评审（价值/创新性/可行性） |
| 产品经理拆解需求 | 中书省选题论证 + 研究 WBS 拆解 |
| 项目经理跟进里程碑 | 尚书省 PMO 派发、督办、汇总 |
| 研发 / 数据 / 写作部门分工 | 兵部实验、户部数据文献、礼部论文 |
| QA + 合规审计上线前把关 | 刑部科研诚信审计 + 门下省投稿前内审 |
| 每日站会 / 行业情报 | 早朝官每日领域科研晨报 |
| 项目复盘与知识沉淀 | 奏折阁归档 + 结题复盘 |

**核心原则：**
1. **无评审，不推进** —— 每个阶段必须过门禁（Gate），门禁由非执行方评审，执行方不能自己放行自己。
2. **先假设，后实验** —— 任何实验必须先有书面研究假设与实验设计，禁止"先跑起来看看"。
3. **可复现是底线** —— 没有实验记录、环境快照、数据来源的结论一律视为未完成。
4. **学术诚信红线** —— 严禁编造文献、伪造数据、抄袭。刑部对红线问题有一票否决权。

## 三、科研生命周期：八阶段 + 六道门禁

```
旨意(研究意向)
   │
   ▼
① 选题与立项 ──────────── G1 立项评审（门下省）
   │ 中书省主导，户部文献预检
   ▼
② 文献调研 ──────────── G2 调研评审（门下省）
   │ 户部主导，确认研究空白
   ▼
③ 方案设计（开题） ────── G3 开题评审（门下省）★ 最重要的一道关
   │ 中书省主导，兵部/户部/工部会签
   ▼
④ 实验与数据 ────────── G4 中期检查（尚书省 + 刑部）
   │ 兵部主导，工部保环境，户部管数据
   ▼
⑤ 分析与结论
   │ 户部统计分析，兵部消融/稳健性验证
   ▼
⑥ 论文写作 ──────────── G5 写作内审（门下省）
   │ 礼部主导，全员供稿
   ▼
⑦ 内审与合规 ────────── G6 投稿评审（门下省 + 刑部）★ 双签放行
   │ 门下省模拟同行评审，刑部诚信/合规终审
   ▼
⑧ 投稿与归档
     礼部产出投稿包，尚书省结题归档，吏部复盘绩效
```

### 阶段定义与门禁标准

#### ① 选题与立项 —— G1 立项评审
- **责任**：中书省（主导）、户部（文献预检）
- **产出**：`立项建议书`（研究问题、预期贡献、初步可行性、粗粒度预算）
- **门禁通过标准**：研究问题清晰可证伪；有明确创新点假设；初步文献预检未发现完全重复工作；资源可承受。
- **封驳典型原因**：问题太大无法证伪 / 与已有工作重复 / 无明显增量贡献。

#### ② 文献调研 —— G2 调研评审
- **责任**：户部（主导）、中书省（空白点判断）
- **产出**：`文献调研报告` + 结构化文献清单（含出处，可溯源）
- **门禁通过标准**：覆盖该方向主要流派与近 2-3 年关键进展；明确列出 ≥3 篇最相关工作及与本课题差异；研究空白（Research Gap）陈述成立。
- **红线**：所有引用必须真实可查，刑部可随时抽查。

#### ③ 方案设计（开题）—— G3 开题评审 ★
- **责任**：中书省（主导），兵部（实验设计）、户部（数据与统计方案）、工部（环境方案）会签
- **产出**：`开题报告`（假设、方法、实验设计、评估指标、里程碑、风险与回退方案）
- **门禁通过标准**：假设可检验；实验设计含基线/对照；评估指标明确；有失败预案；里程碑可验收。
- **说明**：开题不过，禁止进入实验阶段。这是资源消耗前最后一道关。

#### ④ 实验与数据 —— G4 中期检查
- **责任**：兵部（主导）、工部（环境与追踪）、户部（数据质量）
- **产出**：实验记录、数据集版本、环境快照、中期结果
- **门禁通过标准**：实验记录完整（配置/随机种子/环境）；数据可追溯；结果可复现；里程碑偏差有解释。
- **阻塞处理**：实验失败不是阻塞理由本身——记录失败、分析原因、提请变更方案才是标准动作。

#### ⑤ 分析与结论
- **责任**：户部（统计分析）、兵部（消融与稳健性）
- **产出**：`结果分析报告`（主结果、消融、显著性/稳健性、局限性）
- **质量标准**：结论不超出数据支持范围；负面结果如实记录；局限性必须写明。

#### ⑥ 论文写作 —— G5 写作内审
- **责任**：礼部（主导）、各部门供稿
- **产出**：论文初稿（结构完整：摘要/引言/相关工作/方法/实验/结论）
- **门禁通过标准**：故事线清晰（问题→空白→方法→证据→结论）；图表自明；引用完整且与文献清单一致；无夸大表述。

#### ⑦ 内审与合规 —— G6 投稿评审 ★ 双签放行
- **责任**：门下省（模拟同行评审）+ 刑部（诚信与合规终审）
- **产出**：内审意见及修改记录、合规审计报告
- **门禁通过标准**：
  - 门下省：以挑剔审稿人视角给出接收/修改意见，重大方法论问题必须解决；
  - 刑部：引用真实性、原创性、数据真实性、伦理合规全部通过。
- **双签**：两方均通过才可进入投稿，任一方否决即退回。

#### ⑧ 投稿与归档
- **责任**：礼部（投稿包）、尚书省（结题）、吏部（复盘）
- **产出**：投稿包（正文/附录/图表源文件/可复现材料/投稿信）、归档奏折、结题复盘
- **归档要求**：全部中间产物（立项书/调研/开题/实验记录/分析/内审意见）随奏折归档，保证任何结论可回溯到证据。

## 四、看板状态与科研阶段的映射

底层任务状态机不变，科研阶段通过任务标题前缀与子任务（todo）体现：

| 看板状态 | 科研含义 |
|----------|----------|
| Inbox / Zhongshu | 选题论证与方案起草中 |
| Menxia | 处于某道门禁评审中（G1/G2/G3/G5/G6） |
| Assigned | 评审通过，待 PMO 派发 |
| Doing | 文献/实验/分析/写作执行中 |
| Review | 尚书省汇总成果，准备回奏 |
| Done | 阶段交付物归档（或项目结题） |
| Blocked | 实验失败/资源不足/待皇上决策 |

**推荐做法**：一个研究项目 = 一个主任务（ZYQ），八阶段作为 todo 子任务逐项推进；每道门禁的评审意见写入 flow 流转记录，形成完整审计链。

## 五、三条标准科研工作流

### A. 完整研究项目（论文导向）
走全部八阶段六道门禁。适用于正式科研课题。
> 示例旨意：「圣旨：立项研究<课题>，按完整科研流程推进，目标产出可投稿论文。」

### B. 文献综述快线
走 ①② + 写作 + 内审精简版。适用于快速了解一个领域。
> 示例旨意：「圣旨：对<领域>做文献综述，产出调研报告，需过门下省评审。」

### C. 实验复现 / 验证
走 ③（简化开题）④⑤ + 刑部可复现性审计。适用于复现论文、验证想法。
> 示例旨意：「圣旨：复现<论文/方法>，兵部执行，刑部做可复现性审计。」

## 六、质量红线（刑部一票否决）

1. **严禁编造文献**：所有引用必须真实存在且可溯源。
2. **严禁伪造/篡改数据**：实验数据必须来自真实执行记录。
3. **严禁抄袭**：写作必须原创表述，引用规范标注。
4. **严禁隐瞒负面结果**：失败实验与负面结果必须如实归档。
5. **伦理合规**：涉及人类受试者、隐私数据、动物实验等必须先过伦理审查。
