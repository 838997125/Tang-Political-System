# 📋 科研 SOP 检查清单 · Standard Operating Procedures

> 配套 [科研流程总纲](research-workflow.md) 使用。各 Agent 在对应阶段必须逐项完成检查清单，并将完成情况通过 `kanban_update.py todo` 上报看板。
>
> 原则：**检查项没勾完，阶段不算完成。**

---

## SOP-1 选题与立项（中书省主导）

- [ ] 用一句话陈述研究问题（可证伪，非口号）
- [ ] 说明预期贡献：理论贡献 / 方法贡献 / 应用贡献，至少其一
- [ ] 户部文献预检：检索 ≥10 篇最相关工作，确认无完全重复
- [ ] 初步评估资源：数据可得性、算力、时间、工具
- [ ] 形成《立项建议书》，提交门下省 G1 评审

**立项建议书模板：**
```markdown
# 立项建议书
## 研究问题（一句话）
## 背景与动机（≤300字）
## 预期贡献与创新点假设
## 初步文献预检结论（户部）
## 资源预估（数据/算力/时间）
## 主要风险
```

---

## SOP-2 文献调研（户部主导）

- [ ] 制定检索策略：关键词组合、数据库来源、时间范围
- [ ] 收集文献并建立结构化清单：标题/作者/年份/来源/链接/一句话总结
- [ ] 按流派/方法对文献分类，绘制领域脉络
- [ ] 选出 ≥3 篇最相关工作，逐一对比与本课题的差异
- [ ] 撰写研究空白（Research Gap）陈述
- [ ] 全部引用经刑部抽查可溯源
- [ ] 形成《文献调研报告》，提交门下省 G2 评审

**文献清单格式（每条）：**
```markdown
- [标题] 作者, 年份,  venue. 链接/DOI
  核心方法：… | 主要结论：… | 与本课题关系：…
```

---

## SOP-3 方案设计 / 开题（中书省主导，兵部/户部/工部会签）

- [ ] 明确研究假设（H1, H2…），每条假设对应可检验的实验
- [ ] 兵部：实验设计——基线、对照组、消融方案、复现步骤
- [ ] 户部：数据方案——数据来源、规模、划分、预处理、统计检验方法
- [ ] 工部：环境方案——依赖版本、实验追踪、代码与数据版本管理
- [ ] 评估指标：主指标 + 辅助指标，明确"怎样算成功"
- [ ] 里程碑计划：每阶段交付物与验收标准
- [ ] 风险登记册 + 失败回退方案
- [ ] 形成《开题报告》，提交门下省 G3 评审（**未通过禁止开工实验**）

---

## SOP-4 实验与数据（兵部主导，工部/户部协同）

- [ ] 工部搭建并冻结实验环境（依赖清单、版本快照）
- [ ] 兵部按开题方案执行实验，**每组实验必留实验记录**
- [ ] 户部验收数据质量（完整性、分布、泄漏检查）
- [ ] 所有实验接入追踪（配置、指标、产物版本）
- [ ] 失败实验同样记录并归因，禁止只保留成功结果
- [ ] 尚书省组织 G4 中期检查，刑部抽查可复现性

**实验记录模板（每组实验一份）：**
```markdown
# 实验记录 EXP-NNN
- 对应假设：H?
- 目的：
- 配置：超参 / 随机种子 / 数据版本
- 环境：依赖版本 / 硬件
- 结果：原始指标 + 产物路径
- 结论：支持/不支持假设，或需补充实验
- 复现步骤：
```

## SOP-5 分析与结论（户部 + 兵部）

- [ ] 户部：主结果统计分析，必要的显著性检验
- [ ] 兵部：消融实验，验证各组件贡献
- [ ] 兵部：稳健性检查（不同种子/数据划分/参数扰动）
- [ ] 结论边界：明确结论在什么条件下成立
- [ ] 如实撰写局限性与负面结果
- [ ] 形成《结果分析报告》

---

## SOP-6 论文写作（礼部主导）

- [ ] 先写故事线：问题 → 空白 → 方法 → 证据 → 结论（一页以内）
- [ ] 按目标 venue 模板组织结构：摘要/引言/相关工作/方法/实验/结论
- [ ] 图表自明：坐标轴、单位、图例、误差线齐全
- [ ] 相关工作部分与文献清单一一对应，无漏引无虚构
- [ ] 语言检查：无夸大表述（避免"首次""完美""远超"等无证据措辞）
- [ ] 形成论文初稿，提交门下省 G5 写作内审

---

## SOP-7 内审与合规（门下省 + 刑部，双签）

**门下省 · 模拟同行评审：**
- [ ] 以挑剔审稿人视角审查：创新性、方法严谨性、实验充分性、表述清晰度
- [ ] 按"接收 / 小修 / 大修 / 拒稿"给出结论与具体意见
- [ ] 重大方法论问题必须解决并留修改记录，不允许"带问题上路"

**刑部 · 诚信与合规终审：**
- [ ] 引用真实性：逐条核查文献真实存在
- [ ] 原创性：查重，确认无抄袭
- [ ] 数据真实性：论文数据与实验记录一致
- [ ] 可复现性：按实验记录可重跑主结果
- [ ] 伦理合规：受试者/隐私/授权等（如适用）
- [ ] 出具《合规审计报告》

**两方均通过 → G6 放行；任一方否决 → 退回对应阶段。**

---

## SOP-8 投稿与归档（礼部 + 尚书省 + 吏部）

- [ ] 礼部准备投稿包：正文、附录、图表源文件、可复现材料、投稿信
- [ ] 核对目标 venue 的格式与材料要求
- [ ] 尚书省结题：归档全部中间产物（立项/调研/开题/实验/分析/内审）
- [ ] 奏折阁生成完整流转时间线，保证结论可回溯
- [ ] 吏部组织复盘：流程哪里卡了、评审意见分布、下次改进项

**投稿包清单：**
```markdown
submission/
├── main.pdf / main.tex        # 正文
├── appendix.pdf               # 附录（如有）
├── figures/                   # 图表源文件
├── reproducibility/           # 代码、环境清单、实验记录索引
├── cover_letter.md            # 投稿信
└── compliance_report.md       # 刑部合规审计报告
```
