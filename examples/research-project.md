# 案例：一个完整科研项目如何从旨意走到投稿包

> 本案例演示「完整研究项目」工作流（八阶段六道门禁）的端到端运转。
> 流程定义见 [科研流程总纲](../docs/research-workflow.md)，各阶段检查项见 [科研 SOP](../docs/research-sop.md)。

## 旨意

```
圣旨：立项研究「基于检索增强的小模型领域问答幻觉抑制方法」（领域：人工智能/NLP），
按完整科研流程推进，目标产出：可投稿论文。
资源约束：单卡消费级 GPU，三周内。
```

## 流转全过程

### ① 选题与立项（中书省 → 门下省 G1）

**中书省**接旨，创建任务 `ZYQ-20260301-001`，起草《立项建议书》：
- 研究问题：在检索增强生成（RAG）场景下，小参数模型（≤7B）的领域问答幻觉能否通过检索结果可信度加权显著降低？
- 预期贡献：方法贡献（可信度加权解码策略）+ 应用贡献（低成本领域问答方案）
- 户部文献预检：检索 12 篇最相关工作，未发现相同方法
- 资源预估：单卡可承载 7B 模型推理与轻量微调

**门下省 G1 评审**：✅ 准奏（问题可证伪、有创新点假设、资源可承受；建议补充与 2 篇 2025 年幻觉抑制工作的差异分析）。

### ② 文献调研（户部 → 门下省 G2）

**户部**按 SOP-2 执行：
- 产出 32 篇结构化文献清单（标题/作者/年份/venue/链接/一句话总结）
- 按流派分类：检索增强、幻觉检测、解码策略、可信度估计
- 3 篇最相关工作逐篇对比，明确本课题差异点
- 研究空白陈述：现有可信度加权多针对大模型，小模型领域问答场景缺乏系统验证

**门下省 G2 评审**：✅ 准奏。

### ③ 方案设计 / 开题（中书省会签 → 门下省 G3）

**中书省**组织会签，产出《开题报告》：
- H1：可信度加权解码较基线显著降低幻觉率；H2：该方法在小模型上收益大于大模型
- 兵部实验设计：2 个基线 + 消融（去掉加权/去掉检索）+ 3 个随机种子
- 户部数据方案：2 个公开领域问答数据集，8/1/1 划分，人工标注幻觉率抽检 200 条
- 工部环境方案：依赖冻结 + 实验追踪，代码/数据版本管理
- 评估指标：主指标幻觉率，辅助指标答案准确率、延迟
- 里程碑：W1 环境与基线、W2 主实验、W3 分析与写作

**门下省 G3 评审**：❌ 封驳（第一轮）——「缺少幻觉率的人工标注一致性方案；H2 需要大模型对照组，与资源约束冲突」。**中书省修订**：增加双人标注 + 一致性检验；H2 改为「在 3B/7B 两档模型间比较收益」。**G3 复审**：✅ 准奏。

### ④ 实验与数据（工部 + 兵部 + 户部 → G4 中期检查）

- **工部**冻结环境，接入实验追踪
- **兵部**执行基线与主实验，每组实验留 EXP-NNN 实验记录（配置/种子/环境/结果/复现步骤）
- 第 4 组实验失败（显存溢出）：兵部记录失败并归因，改为梯度累积方案后继续——**失败记录一并归档**
- **户部**验收数据质量，无泄漏
- **尚书省**主持 G4 中期检查，**刑部**抽查 2 组实验可复现：✅ 通过

### ⑤ 分析与结论（户部 + 兵部）

- 户部：主结果统计 + 显著性检验，H1 成立（幻觉率相对基线下降，p<0.05）
- 兵部：消融显示加权策略贡献主要收益；3B/7B 对比部分支持 H2
- 如实写明局限性：仅覆盖中文领域问答、人工标注规模有限

### ⑥ 论文写作（礼部 → 门下省 G5）

- 礼部先出一页故事线，再写全结构初稿；图表自明；引用与文献清单逐条核对
- **门下省 G5 内审**：小修——「引言动机与实验结论呼应不足；图 3 缺误差线」。礼部逐条修改并留记录：✅ 通过

### ⑦ 内审与合规（门下省 + 刑部 G6 双签）

- **门下省**模拟顶会审稿：小修，2 条意见（相关工作补充 1 篇、局限性展开）
- **刑部**合规终审：引用真实性 ✅ / 原创性 ✅ / 数据与实验记录一致 ✅ / 可复现性 ✅ / 伦理（公开数据集）✅，出具《合规审计报告》
- **双签放行**

### ⑧ 投稿与归档（礼部 + 尚书省 + 吏部）

- 礼部产出投稿包：正文 / 附录 / 图表源文件 / 可复现材料 / 投稿信 / 合规审计报告
- 尚书省结题：全部中间产物随奏折归档，奏折阁可查看完整五阶段时间线
- 吏部复盘：G3 封驳 1 次（实验设计问题）、G5 小修 1 次——建议下次开题时默认纳入标注一致性方案

## 涉及部门与门禁一览

| 阶段 | 主导 | 门禁 | 结果 |
|------|------|------|------|
| 立项 | 中书省 | G1 | ✅ 一次通过 |
| 调研 | 户部 | G2 | ✅ 一次通过 |
| 开题 | 中书省 | G3 | ❌→✅ 封驳 1 轮后通过 |
| 实验 | 兵部 | G4 | ✅ 中期检查通过 |
| 写作 | 礼部 | G5 | 小修后通过 |
| 内审 | 门下省+刑部 | G6 | 双签放行 |
| 投稿归档 | 礼部/尚书省/吏部 | — | 结题 |

**这个案例体现了科研流程的核心价值**：开题阶段的封驳拦住了实验设计缺陷（否则实验做完才发现标注方案缺失，返工成本更高）；失败实验被记录而非丢弃；任何结论都能沿奏折回溯到实验记录。
